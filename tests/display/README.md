# Тестирование главного экрана

## Тестовый скетч: main_screen_test.ino

Тестовый скетч для проверки отрисовки главного экрана на реальном оборудовании.

### Требования

- Arduino Nano (ATmega328P)
- OLED дисплей SSD1306 128x64 (I2C или SPI)
- Библиотека U8g2lib

### Подключение дисплея (SPI 4-wire)

- CS1 → D10
- RES → D8
- A0 (DC) → D9
- SCL → D13
- SI (DATA) → D11
- VCC → 5V
- GND → GND

### Использование

1. Откройте `main_screen_test.ino` в Arduino IDE
2. Выберите плату: **Arduino Nano**
3. Выберите процессор: **ATmega328P (Old Bootloader)**
4. Загрузите скетч на Arduino
5. Откройте Serial Monitor (9600 baud)

### Команды через Serial Monitor

- `0` - Переключить на режим **Growing** (РОСТ)
- `1` - Переключить на режим **Spring** (ВЕСНА)
- `2` - Переключить на режим **Summer** (ЛЕТО)
- `3` - Переключить на режим **Autumn** (ОСЕНЬ)
- `l` - Переключить состояние освещения (ON/OFF)
- `p` - Переключить состояние помпы (ON/OFF)
- `t` - Увеличить час на 1

### Что тестируется

**Задача 2.1: Отрисовка режима работы системы**
- Отображение режима в инвертированном режиме
- Корректность текста для всех режимов (РОСТ, ВЕСНА, ЛЕТО, ОСЕНЬ)
- Позиционирование (координаты 0,0, ширина 30px, высота 8px)
- Отступ текста (2px от левого края)

### Ожидаемый результат

В левом верхнем углу дисплея должен отображаться:
- Залитый черный прямоугольник (30x8px)
- Белый текст с названием режима (первые 4 символа)
- Текст должен быть читаемым и правильно позиционированным

### Отладка

При включенном `SERIAL_DEBUG` в Serial Monitor будут выводиться:
- Сообщения об инициализации
- Информация о вызовах методов рендеринга
- Текущие значения состояния системы
