Основная функция:
С определённой периодичностью опрашивать датчик влажности почвы, при снижении влажности ниже определённого уровня осуществить полив.

Состояния устройства:
ER_OK               0x00          // успех
ER_DRYSOIL          0x01          // сухая земля, подготовка к поливу
ER_IRRIGATION       0x02          // производится полив
ER_OUTOFWATER       0x03          // кончилась вода, почва не увлажнилась после полива
ER_UNREACH          0x10          // дисплей недоступен


Настраиваемые переменные, сохраняемые в EEPROM, их значения по умолчанию:
IRRIGATE_TIME       18000        // время одного полива (миллисекунды)
IRRIGATE_COUNT      6            // количество поливов на одну ирригацию
IRRIGATE_PERIOD     600          // пауза между поливами и опросами датчика (секунды)
MIN_HUMIDITY        58           // минимальная нормальная влажность почвы в процентах

ANALOG_HUM_ZERO     500         // показатели аналогового датчика при сухой почве (0%)
ANALOG_HUM_FULL     180         // показатели аналогового датчика при залитой почве (100%)

STAB_PAUSE          60          // время стабилизации датчика после включения питания (миллисекунды)

В EEPROM необходимо сохранять данные в виде структуры, содержащей контрольную сумму сохранённых параметров.

Добавить данные в EEPROM:
- режим: авто/фото
- длительность вегетации/цветения в днях (если авто - общая длительность)
- продолжительность светового дня на вегетации/цветении в часах (если авто - просто продолжительность)

------------

Необходимо добавить управление светом, настройки периодов вегетации и цветения. Для этого следует добавить поддержку RTC (real time clock).

При включении:
Считать структуру из EEPROM. Проверить контрольную сумму. При совпадении CRC назначить настраиваемым параметрам считанные из
EEPROM значения и перейти в режим выращивания, в противном случае присвоить значения по умолчанию и перейти в меню настройки.



Меню настройки:
- Настройка режима (авто/фото) -> подменю
        для авто:
                длительность цикла (по умолчанию 80 дней)
                продолжительность светового дня (по умолчанию 18/6)
        для фото:
                длительность вегетации (по умолчанию 30 дней ?)
                длительность цветения (по умолчанию 50 дней ?)
                продолжительность дня на вегетации (по умолчанию 20/4)
                продолжительность дня на цветении (по умолчанию 12/12)
