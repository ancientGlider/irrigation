# Конечный автомат системы автоматического полива растений

## Обзор системы

Система реализует конечный автомат для управления автоматическим поливом растений. Система управляется циклическим вызовом контроллера FSM из основной программы.

При инициализации система входит в состояние **Stopping**.

> Примечание: во всём документе выражения «помпа включена/выключена» описывают логическое состояние FSM. Фактический уровень сигнала на управляющем пине задаётся параметром `highIsOn`, передаваемым в `Watering::begin()` (HIGH по умолчанию включает помпу, LOW — выключает; при `highIsOn = false` уровни меняются местами).

## Переменные состояния

### Параметры конфигурации (константы)

| Параметр | Описание |
|----------|---------|
| `SoilMoistureStartPercent` | Порог влажности для начала автоматического полива (%) |
| `SoilMoistureStopPercent` | Порог влажности для остановки полива (%) |
| `WateringDurationSec` | Длительность включенной помпы при поливе (сек) |
| `WateringPauseSec` | Пауза между попытками полива (сек) |
| `WateringMaxAttempts` | Максимальное число попыток полива перед переходом в OutOfWater |
| `CleaningDurationSec` | Длительность включенной помпы при очистке (сек) |
| `CleaningPauseSec` | Пауза между циклами очистки (сек) |
| `CleaningCycles` | Количество циклов очистки |

### Переменные состояния

| Переменная | Описание |
|-----------|---------|
| `currentState` | Текущее состояние FSM |
| `previousState` | Предыдущее состояние (сохраняется при переходе в ManualWatering и ManualCleaning) |
| `WateringAttempts` | Счётчик попыток полива или циклов очистки |
| `currentHumidity` | Последнее полученное значение влажности почвы |

## Описание состояний

### Режим контроля

### 1. Idle
**Помпа**: выключена

**Возможные входы**:
- Из AutoPause (автоматический переход)
- Из ManualPause (автоматический переход)
- Из OutOfWater (автоматический переход)
- Из любого состояния по принудительной команде, инициированной внешней системой

Система контролирует влажность почвы.

**Проверка условия выхода**:
- Если `currentSoilMoisture <= SoilMoistureStartPercent`:
  - **Автоматический переход** → AutoPause

---

### Режим автоматического полива

### 2. AutoPause
**Помпа**: выключена

**Возможные входы**:
- Из Idle (автоматический переход)
- Из AutoWatering (автоматический переход)

Система ожидает между попытками полива. Запускается таймер на время `WateringPauseSec`.

**При входе**:
- Если переход выполнен из `Idle`, сбросить `WateringAttempts = 0`
- Запустить таймер на время `WateringPauseSec`

**После истечения таймера выполняется проверка условий выхода (в указанном порядке)**:

1. Если `currentSoilMoisture >= SoilMoistureStopPercent`:
   - **Автоматический переход** → Idle

2. Иначе, если `WateringAttempts < WateringMaxAttempts`:
   - Увеличить: `WateringAttempts++`
   - **Автоматический переход** → AutoWatering

3. Иначе, если `currentSoilMoisture > SoilMoistureStartPercent`:
   - **Автоматический переход** → Idle

4. Иначе:
   - **Автоматический переход** → OutOfWater

---

### 3. AutoWatering
**Помпа**: включена

**Возможные входы**:
- Из AutoPause (автоматический переход)

Система активно поливает растение. Запускается таймер на время `WateringDurationSec`.

**При входе**:
- Запустить таймер на время `WateringDurationSec`

**После истечения таймера**:
- **Автоматический переход** → AutoPause

---

### Режим ручного полива

### 4. ManualWatering
**Помпа**: включена

**Возможные входы**:
- Из любого состояния по принудительной команде, инициированной внешней системой

Система находится в режиме ручного полива, инициированного внешней системой.

**При входе**:
- Сохранить текущее состояние: `previousState = currentState`
- Запустить таймер на время `WateringDurationSec`

**После истечения таймера**:
- Если `previousState == Stopping`:
  - **Автоматический переход** → Stopping
- Иначе:
  - **Автоматический переход** → Idle

---

### Режим очистки

### 5. ManualCleaning
**Помпа**: включена

**Возможные входы**:
- Из ManualPause (автоматический переход)
- Из любого состояния по принудительной команде, инициированной внешней системой

Система находится в режиме очистки помпы.

**При входе в режим очистки (только при первом входе в цикл очистки, а не при повторных входах из ManualPause)**:
- Сохранить текущее состояние: `previousState = currentState`
- Сбросить счётчик: `WateringAttempts = 0`

**При входе**:
- Запустить таймер на время `CleaningDurationSec`

**После истечения таймера**:
- Увеличить: `WateringAttempts++`
- **Автоматический переход** → ManualPause

---

### 6. ManualPause
**Помпа**: выключена

**Возможные входы**:
- Из ManualCleaning (автоматический переход)

Система находится в режиме ожидания между циклами очистки. Запускается таймер на время `CleaningPauseSec`.

**При входе**:
- Запустить таймер на время `CleaningPauseSec`

**После истечения таймера выполняется проверка условий выхода**:

1. Если `WateringAttempts < CleaningCycles`:
   - **Автоматический переход** → ManualCleaning

2. Иначе, если `previousState == Stopping`:
   - **Автоматический переход** → Stopping

3. Иначе:
   - **Автоматический переход** → Idle

---

### Режим отсутствия воды

### 7. OutOfWater
**Помпа**: выключена

**Возможные входы**:
- Из AutoPause (автоматический переход)

Система находится в состоянии отсутствия воды. Запускается таймер на время 86400 секунд (1 сутки).

**При входе**:
- Запустить таймер на 86400 секунд

**После истечения таймера**:
- **Автоматический переход** → Idle

---

### Режим тренировки

### 8. TrainingWaiting
**Помпа**: выключена

**Возможные входы**:
- Из любого состояния по принудительной команде внешней системы

FSM ожидает снижения влажности до уровня `TrainingMoisturePercent`.

**Условие выхода**:
- Если `currentSoilMoisture <= TrainingMoisturePercent`:
  - **Автоматический переход** → `TrainingReady`

---

### 9. TrainingReady
**Помпа**: выключена

**Возможные входы**:
- Из `TrainingWaiting` (автоматический переход)

Система находится в режиме тренировки растения. Запускается таймер на 86400 секунд (1 сутки).

**При входе**:
- Запустить таймер на 86400 секунд

**После истечения таймера**:
- **Автоматический переход** → `Idle`

---

### Режим остановки

### 10. Stopping
**Помпа**: выключена

**Возможные входы**:
- Инициализация системы
- Из ManualWatering (автоматический переход, если `previousState == Stopping`)
- Из ManualPause (автоматический переход, если `previousState == Stopping`)
- Из любого состояния по принудительной команде, инициированной внешней системой

Система находится в состоянии остановки. Это начальное состояние при инициализации.

**Выходы**:
- Только принудительные переходы, инициированные внешней системой

---


При принудительных командах `stop`, `setManualWatering`, `setManualCleaning`, `setIdle`, `setTraining` переход осуществляется согласно таблице принудительных переходов.

---

## Таблица переходов

| Текущее состояние | Условие | Тип перехода | Следующее состояние |
|------------------|---------|-------------|-------------------|
| **Idle** | `soilMoisture <= SoilMoistureStartPercent` | Автоматический | AutoPause |
| **AutoPause** | Таймер истек + `soilMoisture >= SoilMoistureStopPercent` | Автоматический | Idle |
| **AutoPause** | Таймер истек + `attempts < maxAttempts` | Автоматический | AutoWatering |
| **AutoPause** | Таймер истек + `attempts >= maxAttempts` + `soilMoisture > SoilMoistureStartPercent` | Автоматический | Idle |
| **AutoPause** | Таймер истек (иные условия) | Автоматический | OutOfWater |
| **AutoWatering** | Таймер истек | Автоматический | AutoPause |
| **ManualWatering** | Таймер истек + `previousState == Stopping` | Автоматический | Stopping |
| **ManualWatering** | Таймер истек + `previousState ≠ Stopping` | Автоматический | Idle |
| **ManualCleaning** | Таймер истек | Автоматический | ManualPause |
| **ManualPause** | Таймер истек + `attempts < cleaningCycles` | Автоматический | ManualCleaning |
| **ManualPause** | Таймер истек + `attempts >= cleaningCycles` + `previousState == Stopping` | Автоматический | Stopping |
| **ManualPause** | Таймер истек + `attempts >= cleaningCycles` + `previousState ≠ Stopping` | Автоматический | Idle |
| **OutOfWater** | Таймер истек (1 сутки) | Автоматический | Idle |
| **TrainingWaiting** | `soilMoisture <= TrainingMoisturePercent` | Автоматический | TrainingReady |
| **TrainingReady** | Таймер истек (1 сутки) | Автоматический | Idle |
| **Любое состояние** | Команда внешней системы | Принудительный | Idle |
| **Любое состояние** | Команда внешней системы | Принудительный | ManualWatering |
| **Любое состояние** | Команда внешней системы | Принудительный | ManualCleaning |
| **Любое состояние** | Команда внешней системы | Принудительный | TrainingWaiting |
| **Любое состояние** | Команда внешней системы | Принудительный | Stopping |

---

## Принудительные переходы

Принудительные переходы могут быть вызваны из любого состояния в следующие состояния командой, инициированной внешней системой:

- **В Idle**
- **В ManualWatering**: сохраняется `previousState`
- **В ManualCleaning**: сохраняется `previousState`, счётчик попыток обнуляется
- **В TrainingWaiting**
- **В Stopping**: переход завершает любой процесс
