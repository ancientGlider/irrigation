# Модуль таймера RTC (TimerRTC)

## Описание

Модуль реализует таймер на базе часов реального времени DS1302. Работает в секундах (не в миллисекундах), что обеспечивает высокую точность отсчета времени для длительных циклов выращивания.

## Особенности

- Работает в секундах для точного отсчета времени цикла выращивания
- Автоматическая синхронизация с RTC (периодическое обновление времени)
- Корректная обработка переполнения счетчика секунд (100 лет)
- Поддержка сохранения/восстановления initTime для работы с EEPROM

## API

### Конструктор

```cpp
TimerRTC(unsigned long period = 0)
```

Создает таймер RTC с заданным периодом срабатывания в секундах.

**Параметры:**
- `period` - период срабатывания таймера в секундах

### Статические методы

#### `static void begin(uint8_t pin_ena, uint8_t pin_clk, uint8_t pin_dat)`

Инициализирует RTC модуль. Должен быть вызван перед использованием таймера.

**Параметры:**
- `pin_ena` - пин ENA (enable) для DS1302
- `pin_clk` - пин CLK (clock) для DS1302
- `pin_dat` - пин DAT (data) для DS1302

#### `static void end()`

Завершает работу с RTC модулем, освобождает память.

### Методы экземпляра

#### `unsigned long getTime()`

Возвращает количество секунд, прошедших с момента последнего сброса таймера.

**Возвращает:** время в секундах

**Примечание:** Автоматически синхронизируется с RTC периодически (по умолчанию каждые 10 минут).

#### `bool isReady()`

Проверяет, истек ли заданный период. Если период истек, автоматически сбрасывает таймер.

**Возвращает:** `true` если период истек, `false` в противном случае

#### `void setPeriod(unsigned long period, bool dropTimer = false)`

Устанавливает новый период срабатывания таймера.

**Параметры:**
- `period` - новый период в секундах
- `dropTimer` - если `true`, таймер сбрасывается после установки периода

#### `unsigned long getPeriod() const`

Возвращает текущий установленный период таймера.

**Возвращает:** период в секундах

#### `void drop()`

Сбрасывает таймер (осуществляет его перезапуск).

#### `void setTime(unsigned long seconds, bool dropTimer = false)`

Устанавливает текущее время в секундах.

**Параметры:**
- `seconds` - время в секундах (0 - MAX_SECONDS)
- `dropTimer` - если `true`, таймер сбрасывается после установки времени

#### `unsigned long getInitTime() const`

Возвращает значение initTime (для сохранения в EEPROM).

**Возвращает:** значение initTime в секундах

#### `void setInitTime(unsigned long initTime)`

Устанавливает значение initTime (для восстановления из EEPROM).

**Параметры:**
- `initTime` - значение initTime в секундах

## Пример использования

```cpp
#include "timerRTC.h"

// Инициализация RTC
TimerRTC::begin(12, 4, 3); // ENA=12, CLK=4, DAT=3

// Создание таймера с периодом 1 час (3600 секунд)
TimerRTC cycleTimer(3600);

void loop() {
    if (cycleTimer.isReady()) {
        // Выполнить действие каждый час
        Serial.println("One hour passed");
    }
    
    // Получить текущее время цикла
    unsigned long cycleTime = cycleTimer.getTime();
    // ...
}
```

## Технические детали

### Синхронизация с RTC

Модуль автоматически синхронизируется с RTC каждые 10 минут (по умолчанию). Это обеспечивает точность отсчета времени даже при длительной работе системы.

### Обработка переполнения

Модуль корректно обрабатывает переполнение счетчика секунд (происходит через 100 лет) благодаря модульной арифметике для `unsigned long`.

### Работа с EEPROM

Для сохранения состояния таймера при перезагрузке используйте:
- `getInitTime()` - для сохранения в EEPROM
- `setInitTime()` - для восстановления из EEPROM

## Тестирование

Для тестирования модуля используйте файл `timerRTC_test.ino`. Загрузите его на Arduino Nano и следуйте инструкциям в Serial Monitor.

## Примечания

- Требуется библиотека Ds1302 для работы с часами реального времени
- RTC должен быть правильно подключен к Arduino Nano
- Модуль использует статические переменные для работы с RTC (общие для всех экземпляров)
