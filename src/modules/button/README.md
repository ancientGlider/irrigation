# Модуль кнопки (`button`)

## Описание

Модуль реализует неблокирующую обработку кнопки с использованием внутреннего подтягивающего резистора (`INPUT_PULLUP`). Предоставляет фильтрацию дребезга и определение длительного нажатия без использования `delay()`.

## Особенности

- FSM на базе периодического вызова `check()` с использованием `millis()`
- Фильтрация дребезга (25 мс) и определение длинного нажатия (500 мс)
- Компактная реализация — минимум переменных, отсутствие блокирующих задержек
- Состояния: `BUTTON_UNPRESSED`, `BUTTON_PRESSED`, `BUTTON_LONGPRESSED`

## API

### Конструктор

```cpp
explicit Button(uint8_t pin);
```

**Параметры:**
- `pin` — цифровой пин Arduino, к которому подключена кнопка. Пин должен поддерживать режим `INPUT_PULLUP`.

### Методы

#### `void begin()`

Настраивает пин, считывает начальное состояние и подготавливает внутренние таймеры. Вызывать один раз в `setup()`.

#### `void check()`

Выполняет опрос кнопки, обрабатывает дребезг и обновляет состояние. Вызывать часто в `loop()`.

#### `uint8_t getState() const`

Возвращает текущее состояние кнопки:
- `BUTTON_UNPRESSED`
- `BUTTON_PRESSED`
- `BUTTON_LONGPRESSED`

## Пример использования

```cpp
#include "button.h"

#define BUTTON_PIN 3

Button button(BUTTON_PIN);

void setup() {
    Serial.begin(9600);
    button.begin();
}

void loop() {
    button.check();

    switch (button.getState()) {
        case BUTTON_PRESSED:
            Serial.println(F("Button pressed"));
            break;
        case BUTTON_LONGPRESSED:
            Serial.println(F("Long press"));
            break;
        default:
            break;
    }
}
```

## Тестирование

Для проверки используйте `button_test.ino`:

1. Подключите кнопку между выбранным пином и GND
2. Загрузите скетч на Arduino Nano
3. Откройте Serial Monitor (9600 baud)
4. Выполните предложенные действия (короткое и длинное нажатия)

## Примечания

- Все значения времени в миллисекундах определены в заголовочном файле
- Длинное нажатие срабатывает один раз за цикл удержания (после отпускания состояние возвращается в `BUTTON_UNPRESSED`)
- Все сообщения отладки (Serial) на английском языке
