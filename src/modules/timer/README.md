# Модуль системного таймера (Timer)

## Описание

Модуль реализует таймер на базе встроенной функции `millis()` Arduino. Предоставляет функциональность для отсчета времени и определения истечения заданного периода без использования блокирующих задержек (`delay()`).

## API

### Конструктор

```cpp
Timer(unsigned long period = 0, bool dropTimer = true)
```

Создает таймер с заданным периодом срабатывания.

**Параметры:**
- `period` - период срабатывания таймера в миллисекундах
- `dropTimer` - если `true`, таймер сбрасывается при создании

### Методы

#### `unsigned long getTime()`

Возвращает количество миллисекунд, прошедших с момента последнего сброса таймера.

**Возвращает:** время в миллисекундах

**Примечание:** Корректно обрабатывает переполнение `millis()` благодаря модульной арифметике для `unsigned long`.

#### `bool isReady()`

Проверяет, истек ли заданный период. Если период истек, автоматически сбрасывает таймер.

**Возвращает:** `true` если период истек, `false` в противном случае

#### `void setPeriod(unsigned long period, bool dropTimer = true)`

Устанавливает новый период срабатывания таймера.

**Параметры:**
- `period` - новый период в миллисекундах
- `dropTimer` - если `true`, таймер сбрасывается после установки периода

#### `unsigned long getPeriod()`

Возвращает текущий установленный период таймера.

**Возвращает:** период в миллисекундах

#### `void drop()`

Сбрасывает таймер (осуществляет его перезапуск). Время отсчета начинается заново с текущего момента.

## Пример использования

```cpp
#include "timer.h"

Timer timer(1000); // Таймер с периодом 1 секунда

void loop() {
    if (timer.isReady()) {
        // Выполнить действие каждую секунду
        Serial.println("Прошла 1 секунда");
    }
    
    // Другая работа без блокировок
    // ...
}
```

## Особенности реализации

1. **Обработка переполнения**: Модуль корректно обрабатывает переполнение `millis()` (происходит примерно через 49 дней непрерывной работы) благодаря модульной арифметике для `unsigned long`.

2. **Неблокирующая работа**: Все методы работают без использования `delay()`, что позволяет использовать таймер в асинхронных системах.

3. **Автоматический сброс**: Метод `isReady()` автоматически сбрасывает таймер при истечении периода.

## Тестирование

Для тестирования модуля используйте файл `timer_test.ino`. Загрузите его на Arduino Nano и следуйте инструкциям в Serial Monitor.

## Примечания

- При переопределении прерываний таймеров модуль может работать некорректно
- Точность таймера зависит от точности `millis()`, которая может варьироваться в зависимости от нагрузки системы
