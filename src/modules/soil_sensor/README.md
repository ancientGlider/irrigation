# Модуль датчика влажности почвы (`soil_sensor`)

## Описание

Модуль реализует работу с аналоговым датчиком влажности почвы (емкостным или резистивным) с использованием конечного автомата (FSM) для асинхронной работы без блокирующих задержек.

## Особенности

- **Асинхронная работа**: Использование FSM для исключения блокирующих задержек (`delay()`)
- **Управление питанием**: Автоматическое включение питания датчика только на время чтения для защиты от коррозии
- **Калибровка**: Поддержка прямой и обратной зависимости показаний от влажности
- **Периодический опрос**: Автоматический опрос датчика с настраиваемым периодом (по умолчанию 10 минут)
- **Принудительная проверка**: Возможность немедленного чтения данных

## Зависимости

- Модуль `timer` (системный таймер)

## API

### Конструктор

```cpp
SoilSensor(uint8_t pinInput, uint8_t pinVCC, unsigned long checkPeriod = SOIL_SENSOR_DEFAULT_CHECK_PERIOD)
```

**Параметры:**
- `pinInput` - Аналоговый пин Arduino, к которому подключен датчик
- `pinVCC` - Цифровой пин Arduino, управляющий питанием датчика
- `checkPeriod` - Периодичность опроса датчика в миллисекундах (по умолчанию 600000 мс = 10 минут)

### Методы

#### `void begin()`

Инициализирует датчик: настраивает пины и запускает первый цикл чтения.

**Пример:**
```cpp
SoilSensor sensor(A0, 2);
sensor.begin();
```

#### `uint8_t getSensorData(bool forceCheck = false)`

Возвращает относительную влажность почвы в процентах (0-100%).

**Параметры:**
- `forceCheck` - Если `true`, принудительно запускает проверку датчика

**Возвращает:**
- Влажность в процентах (0-100)

**Пример:**
```cpp
uint8_t humidity = sensor.getSensorData();        // Обычное чтение
uint8_t humidityNow = sensor.getSensorData(true); // Принудительное чтение
```

#### `int getRawSensorData(bool forceCheck = false)`

Возвращает сырые показания датчика (0-1023).

**Параметры:**
- `forceCheck` - Если `true`, принудительно запускает проверку датчика

**Возвращает:**
- Сырое значение аналогового входа (0-1023)

**Пример:**
```cpp
int rawValue = sensor.getRawSensorData();
```

#### `void calibrate(int minHumidity, int maxHumidity)`

Устанавливает калибровочные значения для расчета относительной влажности.

**Параметры:**
- `minHumidity` - Значение датчика, соответствующее 0% влажности (0-1023)
- `maxHumidity` - Значение датчика, соответствующее 100% влажности (0-1023)

**Примечания:**
- Для резистивных датчиков: `min < max` (при повышении влажности показания растут)
- Для емкостных датчиков: `min > max` (при повышении влажности показания падают)
- Если `min == max`, калибровка не изменяется (предотвращение деления на ноль)
- Значения автоматически ограничиваются диапазоном 0-1023

**Пример:**
```cpp
// Резистивный датчик: показания растут с влажностью
sensor.calibrate(180, 500);  // 180 = сухо (0%), 500 = влажно (100%)

// Емкостный датчик: показания падают с влажностью
sensor.calibrate(500, 180);  // 500 = сухо (0%), 180 = влажно (100%)
```

## Состояния FSM

Модуль использует конечный автомат с следующими состояниями:

1. **UNINITIALIZED** - Датчик не инициализирован
2. **BEGIN_READING** - Начало чтения (включение питания)
3. **READ_DATA** - Чтение данных (ожидание стабилизации и чтение)
4. **IDLE** - Ожидание следующего цикла опроса

## Константы

- `SOIL_SENSOR_DEFAULT_CHECK_PERIOD` - Периодичность опроса по умолчанию (600000 мс = 10 минут)
- `SOIL_SENSOR_STAB_PAUSE` - Время стабилизации показаний датчика (60 мс)

## Пример использования

```cpp
#include "soil_sensor.h"

#define PIN_SOIL_INPUT  A0
#define PIN_SOIL_VCC    2

SoilSensor sensor(PIN_SOIL_INPUT, PIN_SOIL_VCC);

void setup() {
    sensor.begin();
    
    // Калибровка для резистивного датчика
    sensor.calibrate(180, 500);
}

void loop() {
    // Чтение данных (автоматически обновляется каждые 10 минут)
    uint8_t humidity = sensor.getSensorData();
    
    // Принудительное чтение
    uint8_t humidityNow = sensor.getSensorData(true);
    
    // Сырые показания
    int rawValue = sensor.getRawSensorData();
    
    delay(1000);
}
```

## Принцип работы

1. При вызове `begin()` датчик переходит в состояние `BEGIN_READING`
2. Включается питание датчика (`pinVCC = HIGH`)
3. Устанавливается таймер на время стабилизации (60 мс)
4. После стабилизации читается значение аналогового входа
5. Питание выключается (`pinVCC = LOW`) для защиты от коррозии
6. Устанавливается таймер на период опроса (по умолчанию 10 минут)
7. Датчик переходит в состояние `IDLE`
8. После истечения периода опроса цикл повторяется

## Защита от коррозии

Питание датчика включается только на время чтения (около 60 мс), что предотвращает коррозию электродов датчика при постоянном питании.

## Калибровка

Модуль поддерживает калибровку для обоих типов датчиков:

- **Резистивные датчики**: При повышении влажности сопротивление падает, показания возрастают (`min < max`)
- **Емкостные датчики**: При повышении влажности показания падают (`min > max`)

Формула расчета относительной влажности:
```
humidity = (rawValue - minHumidity) * 100 / (maxHumidity - minHumidity)
```

Результат ограничивается диапазоном 0-100%.

## Тестирование

Для тестирования модуля используйте `soil_sensor_test.ino`:

1. Подключите датчик к указанным пинам
2. Загрузите тестовый скетч на Arduino Nano
3. Откройте Serial Monitor (9600 baud)
4. Следуйте инструкциям в Serial Monitor

## Оптимизация

Модуль оптимизирован для Arduino Nano:
- Использование `inline` методов где возможно
- Минимальное количество переменных
- Эффективное использование памяти
- Асинхронная работа без блокирующих задержек
