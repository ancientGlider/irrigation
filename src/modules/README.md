# Модули системы

## Описание модулей

### soil_sensor
Модуль для работы с датчиком влажности почвы. Поддерживает аналоговые и резистивные датчики с калибровкой.

### air_sensor  
Модуль для работы с датчиком температуры и влажности воздуха (DHT11/DHT22). Использует FSM для асинхронного чтения.

### button
Модуль обработки кнопок с защитой от дребезга и поддержкой длинного нажатия.

### timer
Системный таймер на базе `millis()` для внутренних задержек.

### timerRTC
Таймер на базе часов реального времени DS1302 для отсчета времени цикла выращивания.

## Принципы разработки модулей

1. Все модули используют FSM для асинхронной работы
2. Избегание блокирующих задержек (`delay()`)
3. Оптимизация использования памяти
4. Четкое разделение интерфейса и реализации
