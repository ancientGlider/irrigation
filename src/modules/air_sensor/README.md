# Модуль датчика температуры и влажности воздуха (`air_sensor`)

## Описание

Модуль реализует асинхронное чтение датчиков DHT11/DHT22 на базе конечного автомата (FSM) без использования блокирующих задержек. Периодический опрос и ожидание таймингов выполняются через системный таймер (`Timer`), а критичные участки защищены от прерываний.

## Особенности

- **Асинхронная работа**: FSM исключает использование `delay()` и позволяет опрашивать датчик параллельно с другими задачами
- **Принудительное чтение**: метод `getSensorData()` поддерживает немедленный опрос (force check)
- **Защита от прерываний**: класс `ManageInterrupts` отключает прерывания во время чтения 40 бит данных
- **Проверка контрольной суммы**: данные принимаются только при корректной checksum
- **Поддержка DHT11/DHT22**: данные возвращаются в десятых долях градусов Цельсия и процентов влажности

## Зависимости

- Модуль `timer`
- Arduino core (`Arduino.h`)

## API

### Конструктор

```cpp
AirSensor(uint8_t pin, unsigned long checkPeriod = AIR_SENSOR_DEFAULT_CHECK_PERIOD)
```

**Параметры:**
- `pin` — цифровой пин Arduino, к которому подключен датчик DHT
- `checkPeriod` — период опроса датчика (мс), по умолчанию 2000 мс (2 секунды)

### Методы

#### `void begin()`

Инициализирует датчик: настраивает пин, вычисляет допустимое время ожидания и выполняет первое чтение. В случае ошибки состояние возвращается в `UNINITIALIZED`.

#### `bool getSensorData(int* temperature, int* humidity, bool forceCheck = false)`

Возвращает температуру и влажность воздуха. Значения передаются в десятых долях: например, `253` соответствует 25.3 °C.

**Параметры:**
- `temperature` — указатель для записи температуры (может быть `nullptr`)
- `humidity` — указатель для записи влажности (может быть `nullptr`)
- `forceCheck` — принудительное чтение данных, минуя ожидание периода

**Возвращает:** `true`, если получены новые валидные данные; `false`, если возвращены ранее считанные значения или операция не удалась.

## Состояния FSM

1. `UNINITIALIZED` — датчик не готов к работе
2. `READY` — датчик готов начать чтение
3. `BEGIN_READING` — формирование стартового импульса
4. `READ_DATA` — ожидание завершения чтения и запуск `_checkSensor()`
5. `IDLE` — ожидание следующего периода опроса

## Константы

- `AIR_SENSOR_DEFAULT_CHECK_PERIOD` — период опроса по умолчанию (2000 мс)
- `AIR_SENSOR_TIME_TO_SYNC_READING` — максимальное время ожидания принудительного чтения (300 мс)
- `AIR_SENSOR_PULLUP_TIME` — время подготовки линии (100 мс)
- `AIR_SENSOR_START_SIGNAL_DURATION` — длительность стартового сигнала (20 мс)
- `AIR_SENSOR_TIME_TO_BEGIN_READING` — ожидание ответа датчика (5 мс)
- `AIR_SENSOR_WAITING_SIGNAL_TIME` — лимит ожидания каждого импульса (100 мкс)

## Пример использования

```cpp
#include "air_sensor.h"

#define PIN_AIR_SENSOR 2

AirSensor sensor(PIN_AIR_SENSOR, 3000UL); // Опрос каждые 3 секунды

void setup() {
    Serial.begin(9600);
    sensor.begin();
}

void loop() {
    int temperature;
    int humidity;
    bool updated = sensor.getSensorData(&temperature, &humidity);

    if (updated) {
        Serial.print("Temperature: ");
        Serial.print(temperature / 10.0f, 1);
        Serial.print(" C, Humidity: ");
        Serial.print(humidity / 10.0f, 1);
        Serial.println(" %");
    }

    // Остальной код... без delay()
}
```

## Тестирование

Используйте `air_sensor_test.ino`:

1. Подключите DHT11/DHT22 к указанным пинам
2. Загрузите скетч на Arduino Nano
3. Откройте Serial Monitor (9600 baud)
4. Следуйте инструкциям, чтобы проверить инициализацию, периодические чтения, принудительный опрос и реакцию на ошибки контрольной суммы

## Примечания

- Между принудительными чтениями выдерживайте паузу ≥ 2 секунд (особенно для DHT11)
- При ошибки контрольной суммы метод возвращает `false`; предыдущие валидные данные сохраняются
- Все Serial выводы предназначены для отладки и выполнены на английском языке, в соответствии с требованиями проекта
