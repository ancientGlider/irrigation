# Система автоматического полива растений

Система автоматического полива и выращивания растений на базе Arduino Nano.

## Описание

Проект представляет собой комплексную систему для автоматического выращивания растений с поддержкой:
- Автоматического полива на основе показаний датчика влажности почвы
- Управления освещением по циклам (весна/лето/осень)
- Мониторинга температуры и влажности воздуха
- Настраиваемых циклов выращивания (30-200 дней с настраиваемым проращиванием 3-7 дней)
- Режимов тренировки и очистки

## Особенности

- ✅ Асинхронная работа через FSM (без блокирующих задержек)
- ✅ Модульная архитектура
- ✅ Оптимизация для Arduino Nano (ограниченные ресурсы)
- ✅ Сохранение настроек в EEPROM
- ✅ Поддержка калибровки датчиков
- ✅ Интуитивный интерфейс с OLED дисплеем
- ✅ Точный расчёт текущего времени цикла (день/час/минута) для всех подсистем

## Требования

- Arduino Nano (ATmega328P)
- OLED дисплей SSD1306 (128x64)
- RTC модуль DS1302
- Датчик влажности почвы (аналоговый или резистивный)
- Датчик температуры и влажности воздуха (DHT11/DHT22)

## Библиотеки

- U8g2lib (для дисплея)
- Ds1302 (для RTC)

## Статус разработки

Проект находится в стадии активной разработки. Логика цикла выращивания и освещения обновлена под новые ограничения; следующий фокус — стабилизация и подготовка интерфейса меню настроек.
