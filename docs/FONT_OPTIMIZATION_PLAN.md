## 3. Оптимизация: совпадающие глифы

В моноширинных bitmap-шрифтах (5×8, 6×10) многие символы **визуально идентичны** в кириллице и латинице. Это позволяет хранить один bitmap для обоих кодов.

### 3.1. Полностью идентичные (высокая вероятность)

| Кириллица | Латиница | Комментарий |
|-----------|----------|-------------|
| А | A | Идентичны |
| Е | E | Идентичны |
| О | O | Идентичны |
| С | C | Идентичны |
| а | a | Идентичны |
| е | e | Идентичны |
| о | o | Идентичны |
| с | c | Идентичны |

**Экономия:** 8 глифов × ~5-10 байт = ~40-80 байт на каждый размер шрифта

### 3.2. Похожие (зависит от конкретного шрифта)

| Кириллица | Латиница | Комментарий |
|-----------|----------|-------------|
| М | M | Часто идентичны |
| Т | T | Часто идентичны |
| Х | X | Часто идентичны |
| х | x | Часто идентичны |
| р | p | Иногда идентичны |
| у | y | Иногда идентичны |

**Решение:** Проверить при генерации bitmap, автоматически объединять идентичные.

### 4.2. Система индексации (ключевое решение)

#### Подход: Компактная lookup table с алиасами

**Идея:** Каждый глиф имеет уникальный индекс. Символы с одинаковым отображением (А/A, О/O) ссылаются на один и тот же индекс.

```cpp
// custom_font.h

namespace CustomFont {

// Уникальные индексы глифов (без дубликатов)
enum class GlyphIndex : uint8_t {
    // Спецсимволы (0-14)
    Space = 0,
    Exclaim,      // !
    Percent,      // %
    Period,       // .
    Colon,        // :
    Slash,        // /
    Question,     // ?
    Less,         // <
    Greater,      // >
    Caret,        // ^
    SmallV,       // v (строчная латинская v для стрелки вниз)
    Degree,       // °
    Minus,        // -
    Asterisk,     // *
    ArrowRight,   // ► (или > с жирным начертанием)
    
    // Цифры (15-24)
    Digit0, Digit1, Digit2, Digit3, Digit4,
    Digit5, Digit6, Digit7, Digit8, Digit9,
    
    // Латиница заглавная, используемая напрямую (25-30)
    // A, C, E, O — используются как алиасы для кириллицы
    LatF,         // F (только в CONFIRM)
    LatI,         // I (в CONFIRM)
    LatM,         // M (в MENU, CONFIRM) — также = кир. М
    LatN,         // N (в MENU, CONFIRM) — также ≈ кир. Н (проверить)
    LatR,         // R (в ERR, CONFIRM) — также ≈ кир. Р (проверить)
    LatU,         // U (в MENU)
    
    // Латиница строчная (31-39)
    LatA_lower,   // a — также = кир. а
    LatC_lower,   // c — также = кир. с
    LatD_lower,   // d
    LatI_lower,   // i — также ≈ кир. і (не используется)
    LatM_lower,   // m
    LatN_lower,   // n
    LatR_lower,   // r
    LatU_lower,   // u
    LatX_lower,   // x — также = кир. х
    
    // Кириллица заглавная (40-59)
    // А, Е, О, С — алиасы на латиницу (не хранятся отдельно)
    CyrA,         // А — ALIAS → будет LatA (нужно добавить)
    CyrB,         // Б
    CyrV,         // В
    CyrD,         // Д
    CyrE,         // Е — ALIAS → LatE (нужно добавить)
    CyrZh,        // Ж
    CyrI,         // И
    CyrK,         // К
    CyrL,         // Л
    CyrM,         // М — может быть ALIAS → LatM
    CyrN,         // Н
    CyrO,         // О — ALIAS → LatO (нужно добавить)
    CyrP,         // П
    CyrR,         // Р
    CyrS,         // С — ALIAS → LatC (нужно добавить)
    CyrT,         // Т
    CyrU,         // У
    CyrTs,        // Ц
    CyrCh,        // Ч
    CyrSoftSign,  // Ь
    CyrY,         // Ы
    
    // Кириллица строчная (60-84)
    // а, е, о, с — алиасы на латиницу
    CyrA_lower,   // а — ALIAS → LatA_lower
    CyrB_lower,   // б
    CyrV_lower,   // в
    CyrD_lower,   // д
    CyrE_lower,   // е — ALIAS → LatE_lower (нужно добавить)
    CyrZh_lower,  // ж
    CyrZ_lower,   // з
    CyrI_lower,   // и
    CyrK_lower,   // к
    CyrL_lower,   // л
    CyrM_lower,   // м
    CyrN_lower,   // н
    CyrO_lower,   // о — ALIAS → LatO_lower (нужно добавить)
    CyrP_lower,   // п
    CyrR_lower,   // р
    CyrS_lower,   // с — ALIAS → LatC_lower
    CyrT_lower,   // т
    CyrU_lower,   // у
    CyrKh_lower,  // х — ALIAS → LatX_lower
    CyrTs_lower,  // ц
    CyrCh_lower,  // ч
    CyrShch_lower,// щ
    CyrSoftSign_lower, // ь
    CyrY_lower,   // ы
    CyrYa_lower,  // я
    
    GLYPH_COUNT   // Общее количество уникальных глифов
};

} // namespace CustomFont
```

#### Упрощённый подход с lookup table

Вместо сложного enum, используем **компактную таблицу маппинга**:

```cpp
// custom_font.h

namespace CustomFont {

// Структура глифа
struct Glyph {
    uint8_t width;          // Ширина (для пропорциональных шрифтов, иначе фиксированная)
    const uint8_t* bitmap;  // Указатель на bitmap в PROGMEM
};

// Таблица глифов для каждого размера шрифта
extern const Glyph FONT_5x8_GLYPHS[] PROGMEM;
extern const Glyph FONT_6x10_GLYPHS[] PROGMEM;
extern const Glyph FONT_10x20_GLYPHS[] PROGMEM;

// Количество глифов
extern const uint8_t FONT_5x8_COUNT;
extern const uint8_t FONT_6x10_COUNT;
extern const uint8_t FONT_10x20_COUNT;

/**
 * Получает индекс глифа по Unicode codepoint.
 * Возвращает 0xFF если символ не найден.
 * 
 * Внутри использует lookup table для быстрого поиска.
 */
uint8_t getGlyphIndex(uint16_t codepoint);

/**
 * Отрисовывает строку (UTF-8) заданным шрифтом.
 */
void drawString(U8G2& display, int16_t x, int16_t y, const char* str, FontSize size);

/**
 * Отрисовывает строку из PROGMEM.
 */
void drawStringP(U8G2& display, int16_t x, int16_t y, const char* strP, FontSize size);

/**
 * Возвращает ширину строки в пикселях.
 */
uint8_t getStringWidth(const char* str, FontSize size);

enum class FontSize : uint8_t {
    Small,   // 5×8 — основной текст
    Medium,  // 6×10 — меню
    Large    // 10×20 — крупные числа
};

} // namespace CustomFont
```

### 4.3. Lookup table для маппинга UTF-8 → индекс

Для эффективного поиска используем **разделение на диапазоны**:

```cpp
// custom_font.cpp

namespace CustomFont {

// Таблица маппинга для ASCII (0x20-0x7F)
// Индекс = код - 0x20, значение = индекс глифа или 0xFF
const uint8_t ASCII_MAP[96] PROGMEM = {
    // 0x20-0x2F: пробел, !, ", #, $, %, &, ', (, ), *, +, ,, -, ., /
    0,     // пробел
    1,     // !
    0xFF,  // " (не используется)
    0xFF,  // #
    0xFF,  // $
    2,     // %
    // ... и т.д.
};

// Таблица маппинга для кириллицы заглавной (0x0410-0x042F = А-Я)
// Индекс = код - 0x0410, значение = индекс глифа или 0xFF
const uint8_t CYRILLIC_UPPER_MAP[32] PROGMEM = {
    40,    // А (0x0410) — или алиас на латиницу
    41,    // Б (0x0411)
    42,    // В (0x0412)
    0xFF,  // Г (0x0413) — не используется
    43,    // Д (0x0414)
    44,    // Е (0x0415) — или алиас
    // ... и т.д.
};

// Таблица маппинга для кириллицы строчной (0x0430-0x044F = а-я)
const uint8_t CYRILLIC_LOWER_MAP[32] PROGMEM = {
    // ...
};

uint8_t getGlyphIndex(uint16_t codepoint) {
    if (codepoint >= 0x20 && codepoint < 0x80) {
        // ASCII
        return pgm_read_byte(&ASCII_MAP[codepoint - 0x20]);
    }
    else if (codepoint >= 0x0410 && codepoint < 0x0430) {
        // Кириллица заглавная А-Я
        return pgm_read_byte(&CYRILLIC_UPPER_MAP[codepoint - 0x0410]);
    }
    else if (codepoint >= 0x0430 && codepoint < 0x0450) {
        // Кириллица строчная а-я
        return pgm_read_byte(&CYRILLIC_LOWER_MAP[codepoint - 0x0430]);
    }
    else if (codepoint == 0x0401) {
        // Ё
        return GLYPH_YO_UPPER;
    }
    else if (codepoint == 0x0451) {
        // ё
        return GLYPH_YO_LOWER;
    }
    // Спецсимволы Unicode
    else if (codepoint == 0x00B0) {
        // ° (градус)
        return GLYPH_DEGREE;
    }
    else if (codepoint == 0x25BA) {
        // ► (стрелка вправо)
        return GLYPH_ARROW_RIGHT;
    }
    
    return 0xFF; // Символ не найден
}

} // namespace CustomFont
```

### 4.4. Обработка алиасов (совпадающих глифов)

**Вариант A: На этапе генерации**

При генерации bitmap-данных скрипт сравнивает глифы и автоматически создаёт алиасы:

```cpp
// Если А и A идентичны, в CYRILLIC_UPPER_MAP[0] записываем индекс латинской A
const uint8_t CYRILLIC_UPPER_MAP[32] PROGMEM = {
    25,    // А → ссылается на глиф латинской A (индекс 25)
    41,    // Б — уникальный
    // ...
};
```

**Вариант B: Явное объявление**

```cpp
// В custom_font.h определяем алиасы как константы
constexpr uint8_t GLYPH_CYR_A = GLYPH_LAT_A;  // А = A
constexpr uint8_t GLYPH_CYR_E = GLYPH_LAT_E;  // Е = E
constexpr uint8_t GLYPH_CYR_O = GLYPH_LAT_O;  // О = O
constexpr uint8_t GLYPH_CYR_S = GLYPH_LAT_C;  // С = C
```

**Рекомендация:** Вариант A (автоматически при генерации) — меньше ручной работы и ошибок.

## 5. Оценка размера

### 5.1. Bitmap данные

**Шрифт 5×8 (5 байт на глиф):**
- Спецсимволы: 15 × 5 = 75 байт
- Цифры: 10 × 5 = 50 байт
- Латиница (с учётом алиасов): ~15 × 5 = 75 байт
- Кириллица (уникальная): ~35 × 5 = 175 байт
- **Итого: ~375 байт**

**Шрифт 6×10 (8 байт на глиф):**
- Аналогично: ~75 × 8 = **~600 байт**

**Шрифт 10×20 (25 байт на глиф):**
- Только цифры + спецсимволы: ~20 × 25 = **~500 байт**

### 5.2. Lookup tables

- ASCII_MAP: 96 байт
- CYRILLIC_UPPER_MAP: 32 байт
- CYRILLIC_LOWER_MAP: 32 байт
- **Итого: ~160 байт**

### 5.3. Код

- Функции отрисовки: ~300-500 байт
- UTF-8 парсинг: ~100-200 байт
- **Итого: ~500-700 байт**

### 5.4. Общий размер кастомных шрифтов

| Компонент | Размер |
|-----------|--------|
| Bitmap 5×8 | ~400 байт |
| Bitmap 6×10 | ~600 байт |
| Bitmap 10×20 | ~500 байт |
| Lookup tables | ~200 байт |
| Код | ~600 байт |
| **Итого** | **~2.3 KB** |

### 5.5. Сравнение

| Вариант | Размер |
|---------|--------|
| Текущие U8g2 шрифты | ~13-16 KB |
| Кастомные bitmap | ~2.3 KB |
| **Экономия** | **~11-14 KB** |

## 6. План реализации

### Этап 1: Инструментарий (скрипт генерации)

**Файл:** `tools/display/generate_custom_font.py`

**Функционал:**
1. Принимает список символов (текстовый файл или строка)
2. Извлекает bitmap из TTF-шрифта или существующего U8g2-шрифта
3. Сравнивает глифы для поиска дубликатов (алиасов)
4. Генерирует C-header файлы с:
   - Массивами bitmap в PROGMEM
   - Lookup tables для маппинга
   - Константами размеров

**Зависимости:** Python 3, Pillow (PIL), fonttools (опционально)

### Этап 2: Создание списка символов

**Файл:** `tools/display/required_chars.txt`

Содержит все используемые символы, сгруппированные по категориям:

# Латиница заглавная

# Латиница строчная
acdeimnrux

°►

### Этап 3: Генерация bitmap-данных

## 7. Риски и митигация

### Риск 1: Качество bitmap ниже, чем у U8g2

**Митигация:** Использовать тот же исходный шрифт, что и U8g2 (например, извлечь bitmap напрямую из U8g2).

### Риск 2: Сложность генерации bitmap

**Митигация:** Использовать готовую библиотеку (Pillow) для рендеринга TTF в bitmap.

### Риск 3: Ошибки в lookup tables

**Митигация:** Автоматическая генерация + юнит-тесты для проверки маппинга.

### Риск 4: Производительность отрисовки

**Митигация:** Lookup tables в PROGMEM с O(1) доступом для ASCII, O(1) для кириллицы по диапазонам.

## 8. Альтернативные подходы (для рассмотрения)

### A. Использовать U8g2 Font Builder

U8g2 имеет инструмент [bdfconv](https://github.com/olikraus/u8g2/wiki/fntgrp) для создания кастомных шрифтов из subset символов.

**Плюсы:** Интеграция с U8g2, проверенный инструмент
**Минусы:** Требует установки, менее гибкий

### B. Использовать готовые компактные шрифты

U8g2 имеет шрифты с суффиксом `_t_` (transparent), которые меньше.

**Плюсы:** Быстро внедрить
**Минусы:** Всё равно включают лишние символы

### C. Гибридный подход

- Для латиницы и цифр — стандартный U8g2 шрифт `_tr`
- Для кириллицы — кастомные bitmap

**Плюсы:** Меньше работы
**Минусы:** Потенциальное несоответствие стилей
