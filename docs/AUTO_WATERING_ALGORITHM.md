# Алгоритм автоматического полива

## Обзор

Модуль `Irrigation::Watering` реализует автоматический полив растений на основе конечного автомата (FSM). Алгоритм контролирует влажность почвы и автоматически включает помпу при необходимости, обеспечивая оптимальное увлажнение без участия пользователя.

## Параметры алгоритма

Все параметры читаются из `Settings::Manager`:

| Параметр | Ключ настройки | По умолчанию | Описание |
|----------|----------------|--------------|----------|
| Порог старта | `SoilMoistureStartPercent` | 58% | Влажность, при которой начинается полив |
| Порог остановки | `SoilMoistureStopPercent` | 85% | Влажность, при которой полив прекращается |
| Длительность полива | `WateringDurationSec` | 18 сек | Время работы помпы за одну попытку |
| Пауза между попытками | `WateringPauseSec` | 600 сек (10 мин) | Время ожидания для впитывания воды |
| Макс. попыток | `WateringMaxAttempts` | 6 | Лимит попыток перед ошибкой "нет воды" |

## Пошаговый алгоритм

### Фаза 1: Мониторинг (Idle)

```
СОСТОЯНИЕ: Idle
ПОМПА: выключена
ДЕЙСТВИЯ:
    1. Получить текущую влажность почвы (soilMoisturePercent)
    2. ЕСЛИ влажность <= SoilMoistureStartPercent (58%):
        → Перейти в AutoPause
        → Сбросить счётчик попыток: attempts = 0
```

**Логика:** Система постоянно мониторит влажность. Когда почва становится сухой (ниже порога), запускается цикл полива.

### Фаза 2: Пауза перед поливом (AutoPause)

```
СОСТОЯНИЕ: AutoPause
ПОМПА: выключена
ТАЙМЕР: WateringPauseSec (600 сек)
ДЕЙСТВИЯ:
    1. Ждать истечения таймера паузы
    2. КОГДА таймер истёк:
        а) ЕСЛИ влажность >= SoilMoistureStopPercent (85%):
            → Полив успешен, перейти в Idle
        
        б) ИНАЧЕ ЕСЛИ attempts < WateringMaxAttempts (6):
            → Увеличить счётчик: attempts++
            → Перейти в AutoWatering
        
        в) ИНАЧЕ ЕСЛИ влажность > SoilMoistureStartPercent (58%):
            → Влажность выросла, но не достигла цели
            → Перейти в Idle (частичный успех)
        
        г) ИНАЧЕ:
            → Влажность не растёт после max попыток
            → Перейти в OutOfWater (ошибка)
```

**Логика:** Пауза нужна для впитывания воды в почву. После паузы проверяем результат и решаем, что делать дальше.

### Фаза 3: Активный полив (AutoWatering)

```
СОСТОЯНИЕ: AutoWatering
ПОМПА: включена
ТАЙМЕР: WateringDurationSec (18 сек)
ДЕЙСТВИЯ:
    1. Включить помпу
    2. Ждать истечения таймера
    3. КОГДА таймер истёк:
        → Перейти в AutoPause
```

**Логика:** Помпа работает фиксированное время (одна "попытка" полива). После этого следует пауза для оценки результата.

### Фаза 4: Ошибка "Нет воды" (OutOfWater)

```
СОСТОЯНИЕ: OutOfWater  
ПОМПА: выключена
ТАЙМЕР: 86400 сек (24 часа)
УСЛОВИЕ ВХОДА: 
    - Выполнено max попыток полива
    - Влажность не выросла выше порога старта
ДЕЙСТВИЯ:
    1. Запустить суточный таймер
    2. Отобразить предупреждение пользователю (внешний модуль)
    3. КОГДА таймер истёк:
        → Перейти в Idle (автоматическое восстановление)
    
    АЛЬТЕРНАТИВНЫЙ ВЫХОД:
    - Команда setManualWatering() → ManualWatering
    - Команда setManualCleaning() → ManualCleaning  
    - Команда stop() → Stopping
    - Команда setIdle() → Idle
```

**Логика:** Если после всех попыток влажность не растёт — вероятно, закончилась вода. Система ждёт сутки и пробует снова, или пользователь может вмешаться вручную.

## Блок-схема цикла полива

```
                    ┌─────────────────┐
                    │     START       │
                    │  (Idle state)   │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Влажность <=    │
              НЕТ   │ StartPercent?   │
           ┌────────┤     (58%)       │
           │        └────────┬────────┘
           │                 │ ДА
           │                 ▼
           │        ┌─────────────────┐
           │        │ attempts = 0    │
           │        │ → AutoPause     │
           │        └────────┬────────┘
           │                 │
           │                 ▼
           │        ┌─────────────────┐
           │        │ Ждать паузу     │
           │        │ (600 сек)       │
           │        └────────┬────────┘
           │                 │
           │                 ▼
           │        ┌─────────────────┐
           │   ДА   │ Влажность >=    │
           │◄───────┤ StopPercent?    │──────────────┐
           │        │     (85%)       │              │
           │        └─────────────────┘              │ НЕТ
           │                                        ▼
           │                                ┌─────────────────┐
           │                           ДА   │ attempts <      │
           │                       ┌────────┤ MaxAttempts?    │
           │                       │        │      (6)        │
           │                       │        └────────┬────────┘
           │                       │                 │ НЕТ
           │                       ▼                 ▼
           │              ┌─────────────────┐┌─────────────────┐
           │              │ attempts++      ││ Влажность >     │
           │              │ → AutoWatering  ││ StartPercent?   │
           │              └────────┬────────┘└────────┬────────┘
           │                       │                 │
           │                       ▼           ДА    │    НЕТ
           │              ┌─────────────────┐ ┌──────┴──────┐
           │              │ Включить помпу  │ │             │
           │              │ Ждать 18 сек    │ │             ▼
           │              └────────┬────────┘ │    ┌─────────────────┐
           │                       │          │    │  → OutOfWater   │
           │                       │          │    │  Ждать 24 часа  │
           │                       ▼          │    └────────┬────────┘
           │              ┌─────────────────┐ │             │
           │              │ → AutoPause     │ │             │
           │              │ (повтор цикла)  │ │             │
           │              └────────┬────────┘ │             │
           │                       │          │             │
           │                       └──────────┼─────────────┘
           │                                  │
           │◄─────────────────────────────────┘
           │
           ▼
    ┌─────────────────┐
    │   КОНЕЦ ЦИКЛА   │
    │ (возврат в Idle)│
    └─────────────────┘
```

## Примеры сценариев

### Сценарий 1: Успешный полив с первой попытки

```
Время 0:00   │ Idle         │ Влажность: 55% (< 58%)
             │              │ → Переход в AutoPause, attempts = 0
             │              │
Время 0:00   │ AutoPause    │ Запуск таймера 600 сек
             │              │
Время 10:00  │ AutoPause    │ Таймер истёк, влажность: 55%
             │              │ attempts (0) < max (6) → attempts = 1
             │              │ → Переход в AutoWatering
             │              │
Время 10:00  │ AutoWatering │ Помпа ВКЛ, таймер 18 сек
             │              │
Время 10:18  │ AutoWatering │ Таймер истёк
             │              │ → Переход в AutoPause
             │              │
Время 10:18  │ AutoPause    │ Запуск таймера 600 сек
             │              │
Время 20:18  │ AutoPause    │ Таймер истёк, влажность: 87% (>= 85%)
             │              │ → Переход в Idle (УСПЕХ!)
```

**Итого:** 1 попытка полива, ~20 минут от старта до завершения.

### Сценарий 2: Полив с несколькими попытками

```
Время 0:00   │ Idle         │ Влажность: 50% → AutoPause, attempts = 0
Время 10:00  │ AutoPause    │ Влажность: 52% → attempts = 1 → AutoWatering
Время 10:18  │ AutoWatering │ Помпа отработала → AutoPause
Время 20:18  │ AutoPause    │ Влажность: 62% → attempts = 2 → AutoWatering
Время 20:36  │ AutoWatering │ Помпа отработала → AutoPause
Время 30:36  │ AutoPause    │ Влажность: 78% → attempts = 3 → AutoWatering
Время 30:54  │ AutoWatering │ Помпа отработала → AutoPause
Время 40:54  │ AutoPause    │ Влажность: 88% (>= 85%) → Idle (УСПЕХ!)
```

**Итого:** 3 попытки полива, ~41 минута.

### Сценарий 3: Ошибка "Нет воды"

```
Время 0:00   │ Idle         │ Влажность: 45% → AutoPause, attempts = 0
             │              │ ... (6 попыток полива, влажность не растёт)
Время 61:48  │ AutoPause    │ attempts = 6, влажность: 47% (<= 58%)
             │              │ → OutOfWater (ОШИБКА!)
             │              │
Время 61:48  │ OutOfWater   │ Запуск суточного таймера (86400 сек)
             │              │ Отображение предупреждения пользователю
             │              │
             │ ... (24 часа ожидания или действие пользователя) ...
             │              │
Время 24:61:48│ OutOfWater  │ Таймер истёк → Idle (повторная попытка)
```

### Сценарий 4: Частичный успех

```
Время 0:00   │ Idle         │ Влажность: 50% → AutoPause, attempts = 0
             │              │ ... (6 попыток полива)
Время 61:48  │ AutoPause    │ attempts = 6, влажность: 65% (> 58%, но < 85%)
             │              │ → Idle (частичный успех, мониторинг продолжается)
```

**Логика:** Влажность выросла достаточно, чтобы не считаться критически сухой, но не достигла целевого уровня. Система продолжит мониторинг и запустит новый цикл при необходимости.

## Временные характеристики

| Параметр | Формула | Значение по умолчанию |
|----------|---------|----------------------|
| Мин. время цикла | `WateringPauseSec` | 10 мин |
| Время одной попытки | `WateringDurationSec + WateringPauseSec` | 10 мин 18 сек |
| Макс. время цикла | `(WateringDurationSec + WateringPauseSec) × MaxAttempts` | ~62 мин |
| Время восстановления после ошибки | 24 часа | 24 часа |

## Ключевые особенности реализации

### 1. Неблокирующая архитектура
- Все операции выполняются через FSM без `delay()`
- Метод `process()` вызывается в каждом цикле `loop()`
- Таймеры реализованы через класс `Timer` на базе `millis()`

### 2. Централизованное управление помпой
```cpp
void Watering::_setPump(bool enabled) {
    if (_pumpEnabled == enabled) return;  // Избегаем лишних переключений
    _pumpEnabled = enabled;
    digitalWrite(_pumpPin, (enabled == _highIsOn) ? HIGH : LOW);
}
```

### 3. Сохранение предыдущего состояния
- При ручном вмешательстве (`ManualWatering`, `ManualCleaning`) сохраняется `_previousState`
- После завершения ручного режима система возвращается в корректное состояние

### 4. Валидация параметров
- Все проверки корректности значений выполняются в `Settings::Manager`
- FSM не дублирует валидацию, доверяя настройкам
