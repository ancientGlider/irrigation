## Аудит модулей для главного экрана (задача 1.1)

### Модуль `src/menu/`
- **Статус:** каталог пуст, реализация меню в новой версии не перенесена.  
- **Вывод:** текущий главный экран не зависит от меню напрямую, но при интеграции нужно предусмотреть переход из меню на экран (договориться о точке входа).

### Модуль `irrigation::watering`
- **Основные API:**  
  - `Watering::begin(pinPump, highIsOn)` — инициализация.  
  - `Watering::process(soilMoisturePercent)` — основной цикл FSM, возвращает `WateringState`.  
  - Методы команд (`setManualWatering`, `setTraining`, `stop`, `setIdle` и др.).  
  - `Watering::getState()` — текущий статус FSM.  
  - `Watering::isPumpOn()` — состояние помпы.  
  - `Watering::getRemainingSeconds()` — таймер/пауза в секундах.  
- **Наблюдения:**  
  - Перечисление `WateringState` покрывает все режимы, описанные для экрана (авто, ожидание, тренировка, стоп, нет воды).  
  - Метод `getRemainingSeconds` даёт оставшееся время до следующего события — можно использовать для таймера датчиков/полива.  
  - Отдельного DTO нет — придётся формировать структуру `MainScreenState` из прямых вызовов.

### Модуль `irrigation::growing_cycle`
- **Основные API:**  
  - `GrowingCycle::getCurrentDay()`, `getCurrentHour()`, `getCurrentMinute()` — базовые показатели времени.  
  - `GrowingCycle::getPeriod()` — возвращает `GrowingPeriod` (проращивание/весна/лето/осень/завершён).  
  - `setCurrentDay`, `setCurrentHour` — управление состоянием (не требуется экрану напрямую).  
- **Наблюдения:**  
  - Для экрана достаточно `getCurrentDay()` и `getPeriod()`, а общее количество дней доступно через настройки (потребуется доступ к `Settings`).  
  - Для отображения часов (`HH:MM`) желательно синхронизироваться с `TimerRTC`, но текущий API уже предоставляет часы и минуты.

### Дополнительные выводы
- Для данных о температуре/влажности необходимо обращаться к модулям датчиков (`air_sensor`, `soil_sensor`) или к текущему агрегатору (его пока нет).  
- Следующим шагом следует описать структуру `MainScreenState` и реализовать агрегатор данных (задача 2.4).
