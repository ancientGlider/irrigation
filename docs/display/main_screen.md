# Основной экран (OLED 128×64, U8g2)

## Цель

Предоставить оператору сводный статус системы полива в режиме `Growing`/`Spring`/`Summer`/`Autumn`, быстрое управление ключевыми функциями и понятный отклик на состояние автоматических подсистем.

## Общие требования

- Разрешение дисплея: 128×64 точек, горизонтальная ориентация.
- Библиотека: U8g2 (режим страничного буфера).
- Обновление экрана: не чаще 2 Гц, с частичными перерисовками (FSM без `delay()`).
- Вся текстовая и графическая информация — в монохромном виде.
- Все подписи и иконки должны быть читабельны с расстояния 30–40 см.
- Нижняя строка зарезервирована под подсказки к кнопкам.

## Структура экрана

```
┌─────────────────────────────── 128 px ───────────────────────────────┐
│ Статус режима | Помпа | Освещение | clk:HH | !                       │ ← строка 0 (10 px)
│---------------------------------------------------------------------│
│ Левый столбец (параметры полива)   │ Правый столбец (среда)          │
│  - Режим полива                    │  - Температура воздуха          │
│  - Состояние помпы                 │  - Влажность воздуха            │
│  - Пауза/Таймеры (по ситуации)     │  - Влажность почвы              │
│---------------------------------------------------------------------│
│ Панель контекстных данных (режим Growing)                            │ ← высота 12–16 px
│  - Текущий сезон, день и час цикла                                   │
│---------------------------------------------------------------------│
│ Иконки кнопок: [Settings] [Manual Water] [Force Check] [Display ON/OFF] │
└─────────────────────────────────────────────────────────────────────┘
```

### Верхняя строка (Header, высота ~10 px)

- **Секция режима**: короткое обозначение текущего режима (`GROW`, `SPRG`, `SUMR`, `AUTM`). Вычисляется модулем `GrowingCycle`.
- **Помпа**: иконка капли (`●`/`○`) или `PUMP ON/OFF`.
- **Освещение**: иконка солнца (`☼`) при включенном свете, полумесяц (`☾`) при выключенном. Источник — `LightControl::isLightOn()`.
- **Время суток**: формат `clk:HH:MM`, где `clk` — пиктограмма часов, значения — локальное время цикла (`GrowingCycle`).
- **Внимание**: мигающий символ `!` активируется дисплейным FSM при состояниях полива `Train` и `OutOfWater`, скрывается в остальных режимах.

### Центральный блок (две колонки)

#### Левая колонка — система полива (ширина ~60 px)

- **Режим**: короткие обозначения состояния полива: `Idle`, `Water`, `Wait`, `Train`, `Stop`.
- **Статус помпы**: `Pump: ON/OFF`.
- **Таймер/пауза**: при активных таймерах отображается обратный отсчёт (`Next: 08:15`). Источник — FSM полива/таймеры.
- **Предупреждения** (опционально): строки `No water`, `Check sensor`.

#### Правая колонка — среда (ширина ~60 px)

- **Температура воздуха**: пиктограмма термометра + значение (`therm 23.5°C`). Датчик `AirSensor`.
- **Влажность воздуха**: пиктограмма капли + значение (`hum 54%`).
- **Влажность почвы**: пиктограмма листа/почвы + значение (`soil 68%`, с учётом калибровки).
- Формат чисел — фиксированный, один знак после запятой (при наличии места).

### Панель контекстных данных (режим `Growing`)

- Отображается только в режиме `Growing`.
- Содержимое:
  - `Season: Spring` (или другое актуальное значение).
  - `Cycle day: 24/100`.
  - `Cycle hour: 312`.
### Нижняя панель иконок кнопок (высота ~12 px)

Четыре иконки выровнены по колонкам шириной 32 px:

1. **Настройки** — пиктограмма шестерни.
2. **Полив** — иконка капли/помпы.
3. **Проверка датчиков** — иконка радара или молнии.
4. **Дисплей** — иконка экрана с меткой `ON/OFF`.

## Источники данных и обновление

| Элемент                    | Источник                                   | Период обновления |
|---------------------------|--------------------------------------------|-------------------|
| Режим цикла, сезон        | `GrowingCycle::getPeriod()`                | при смене режима  |
| День/час цикла            | `GrowingCycle::getCurrentDay()/Hour()`     | 1 Гц (RTC)        |
| Состояние полива          | `Watering::getState()`                     | при вызове `process()` |
| Помпа                     | `Watering::isPumpOn()`                     | 1 Гц              |
| Освещение                 | `LightControl::isLightOn()`                | при смене или 1 Гц|
| Влажность почвы           | `SoilSensor::getSensorData()`              | после обновления датчика |
| Температура/влажность воздуха | `AirSensor::getSensorData()`           | после обновления датчика |
| Таймеры/обратные отсчёты  | соответствующие FSM таймеры                | 1 Гц              |

## Требования к реализациям

- **Буферизация**: использовать `U8G2_SSD1306_128X64_NONAME_1_HW_I2C` (page buffer) либо `2`-страничный режим.
- **Шрифты**: основные значения — шрифт 8×8, заголовки/иконки — 10×10. Шрифты хранятся в PROGMEM.
- **FSM обновления**: дисплейный FSM должен опрашивать внешние модули без блокировок, сравнивать новое состояние с текущим и перерисовывать только изменившиеся блоки.
- **Энергосбережение**: автоматическое выключение дисплея через 10 минут бездействия; при выключении перерисовывать только иконку дисплея и гасить содержимое.
- **Тестирование**: предусмотреть мок-режим с подстановкой данных для проверки читаемости.

## Визуальные элементы

- Иконка солнца: заполненный круг с «лучами» (8×8 px).
- Иконка луны: полумесяц из двух дуг (8×8 px).
- Иконка шестерни: зубчатое колесо (12×12 px).
- Иконка капли: капля воды (10×12 px).
- Иконка радара: концентрические окружности с радиальной линией (10×10 px).
- Иконка дисплея: прямоугольник с кнопкой питания (10×8 px).
- **Иконка выхода**: галочка, перечёркнутая крестиком (✓/✗) — обозначает "остановить / выйти из режима" (10×10 px).
- Все пиктограммы — монохромные, рисуются вручную функциями U8g2.

### Иконка "Выход из режима" (Exit)

Используется для кнопки 2 в активных режимах (полив, очистка, тренировка, ошибка). Визуально представляет "отмену" или "возврат в обычный режим":

```
  ╲   ╱
   ╲ ╱
    ╳
   ╱ ╲
  ╱   ╲
```

Альтернативный вариант — квадрат с крестиком внутри (стоп) или стрелка "назад".

## Навигация с кнопками

| Кнопка | Иконка | Действие                  | Ответственный модуль   |
|--------|--------|---------------------------|-------------------------|
| 1      | Gear   | Вход в меню настроек      | `Menu::open()`          |
| 2      | Drop / Exit | Зависит от режима (см. ниже) | `SystemController` |
| 3      | Radar  | Принудительная проверка   | `SystemController::forceSensorCheck()` |
| 4      | Display| Переключение подсветки    | `Display::toggle()`     |

При нажатии любой кнопки дисплейный таймер неактивности сбрасывается.

### Кнопка 2: контекстное поведение

Кнопка 2 меняет своё действие и иконку в зависимости от текущего режима системы:

| Текущий режим (WateringState) | Действие кнопки 2 | Иконка | Вызов |
|-------------------------------|-------------------|--------|-------|
| `Idle`, `AutoPause` | Запуск ручного полива | 💧 Drop (капля) | `setManualWatering()` |
| `AutoWatering`, `ManualWatering` | Остановка полива → Idle | ✗ Exit (выход) | `stopWatering()` |
| `ManualCleaning`, `ManualPause` | Остановка очистки → Idle | ✗ Exit (выход) | `stopWatering()` |
| `TrainingWaiting`, `TrainingReady` | Выход из тренировки → Idle | ✗ Exit (выход) | `stopWatering()` |
| `OutOfWater` | Сброс ошибки → Idle | ✗ Exit (выход) | `stopWatering()` |
| `Stopping` | Нет действия | — | — |

**Логика:** в режимах ожидания (Idle, AutoPause) кнопка запускает ручной полив. В активных режимах (полив, очистка, тренировка, ошибка) кнопка останавливает процесс и возвращает систему в Idle.

## Черновой макет (первое приближение)

```
┌──────────────────────────────────────────────────────────────────────┐
│ GROW | pump● | ☼ | clk:07 | !                                        │
│──────────────────────────────────────────────────────────────────────│
│ Mode:Water     │ 🌡 23.4°C                                            │
│ Pump:ON        │ 💧 52%                                               │
│ Next:08:15     │ 🌱 68%                                               │
│──────────────────────────────────────────────────────────────────────│
│ Sprn   24/120                                                         │
│──────────────────────────────────────────────────────────────────────│
│ [⚙]SET   [💧]WTR   [⚡]CHK   [▢]DSP                                     │
└──────────────────────────────────────────────────────────────────────┘
```

- Строка 0: компактные обозначения режима цикла, состояния помпы, освещения, текущего часа и индикатора внимания.
- Центральный блок: левая колонка охватывает FSM полива, правая — параметры среды.
- Контекстная панель активируется только при режиме `Growing`.
- Нижний ряд — иконки кнопок, подписанные двух-трёхбуквенными подсказками.

### Черновой рендерер (псевдокод)

```c
void MainScreenRenderer::draw(const ScreenState& s) {
  u8g2.clearBuffer();

  // Header
  u8g2.setFont(u8g2_font_5x7_tr);
  u8g2.drawStr(0, 7, s.modeTag);           // "GROW"
  drawPumpIcon(36, 0, s.pumpOn);           // ● / ○
  drawLightIcon(56, 0, s.lightOn);         // ☼ / ☾
  drawClock(76, 0, s.hour);                // clk:HH
  if (s.attention) drawAttention(110, 0);  // мигающий !

  // Left column
  u8g2.drawStr(0, 20, format("Mode:%s", s.wateringModeShort));
  u8g2.drawStr(0, 30, format("Pump:%s", s.pumpOn ? "ON" : "OFF"));
  if (s.nextEventStr) u8g2.drawStr(0, 40, format("Next:%s", s.nextEventStr));

  // Right column
  drawThermometer(68, 12); u8g2.drawStr(80, 20, s.airTempStr);
  drawDrop(68, 22);        u8g2.drawStr(80, 30, s.airHumidityStr);
  drawSoil(68, 32);        u8g2.drawStr(80, 40, s.soilMoistureStr);

  // Growing context panel
  if (s.period == Period::Growing) {
    u8g2.drawHLine(0, 46, 128);
    u8g2.drawStr(0, 55, format("Season:%s", s.seasonStr));
    u8g2.drawStr(64, 55, format("Day %u/%u", s.day, s.totalDays));
    u8g2.drawStr(0, 63, format("Hour %u", s.cycleHour));
  }

  // Button hints
  drawButtonHint(0, 56, ICON_GEAR_12X12, "SET");
  drawButtonHint(32, 56, ICON_DROP_12X12, "WTR");
  drawButtonHint(64, 56, ICON_FORCE_12X12, "CHK");
  drawButtonHint(96, 56, ICON_DISPLAY_12X12, "DSP");

  u8g2.sendBuffer();
}
```

Этот скетч демонстрирует базовое расположение элементов и может служить отправной точкой для дальнейшего уточнения размеров и шрифтов.
