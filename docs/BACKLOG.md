## Переименование режима

### РОСТ → ЦИКЛ

Во всём проекте (документация, код, отображение на дисплее) необходимо переименовать режим "РОСТ" (`Growing`) на "ЦИКЛ" для единообразия с меню:

- [ ] `docs/` — все упоминания "РОСТ", "Growing mode"
- [ ] `src/settings/` — enum `SystemMode::Growing` → обсудить, нужно ли менять enum или только отображение
- [ ] `src/display/` — строки отображения режима на главном экране
- [ ] Тесты — если есть проверки на строковые значения

**Примечание:** enum `SystemMode::Growing` можно оставить как есть (это внутреннее имя), но на дисплее отображать "ЦИКЛ".
